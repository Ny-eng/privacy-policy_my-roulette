# privacy-policy_my-roulette

このリポジトリは、スマートフォン用アプリ「私のルーレット」のプライバシーポリシーを公開するためのものです。

## サイトの閲覧

このサイトはGitHub Pagesで公開されています。以下のURLからアクセスできます：

[https://ny-eng.github.io/privacy-policy_my-roulette/](https://ny-eng.github.io/privacy-policy_my-roulette/)

## ローカルでの確認

ローカルで確認するには、以下のコマンドを実行してください：

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` にアクセスして確認できます。
